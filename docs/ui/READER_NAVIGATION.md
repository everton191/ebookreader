# Navegação enxuta do leitor

A barra principal agora expõe somente Biblioteca, Downloads e Configurações.
A Biblioteca abre na coleção local e tem um único botão **Adicionar livro**,
ligado ao seletor de documentos do Android. Provedores apresentados pelo
Android, inclusive Google Drive quando instalado e autenticado, continuam
disponíveis via SAF sem token próprio.

Foram ocultados os agregadores, notas, scanner, carteira, formulários, URL e
atalhos TechEmpower. As rotas antigas não foram apagadas nesta fase para
reduzir risco de regressão no playback.
